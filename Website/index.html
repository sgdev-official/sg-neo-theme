Strings use gold (#FFD700) and comments stay a quiet grey.

Install SG Neo in under a minute.

Pick the way that fits your editor. The VS Code library is the easiest; the .vsix works offline.

  1. Open the store page with the button on the right, or press Ctrl Shift X in VS Code and search for SG Neo Theme.

  2. Click Install.

  3. Press Ctrl K, then Ctrl T, and choose SG Neo.

VS Code library

Opens the SG Neo page and VS Code offers to install it.

Install from VS Code Library

  1. Download sg-neo-theme.vsix with the button on the right.

  2. In VS Code open Extensions with Ctrl Shift X, click the … menu at the top of the panel, and choose Install from VSIX…

  3. Select the downloaded file, then pick SG Neo with Ctrl K, Ctrl T.

.vsix file

Install .vsix

Prefer the terminal? Run this in the folder with the file:

code --install-extension sg-neo-theme.vsix

  1. Download sg-neo-theme.xml with the button on the right.

  2. Copy it into the Notepad++ themes folder, usually %APPDATA%\Notepad++\themes. Create the folder if it does not exist.

  3. Restart Notepad++, open Settings, then Style Configurator, pick SG Neo from the theme list and click Save & Close.

Notepad++ theme

One XML file. No installer needed.

Install for Notepad++

  1. Open the Open VSX page with the button on the right.

  2. VSCodium, Gitpod and Eclipse Theia read from Open VSX. Open their Extensions panel, search for SG Neo Theme and click Install.

  3. Choose SG Neo as your color theme.
