HOW TO INSTALL

Method 1

From VS Code Library

  1. Click Install from VS Code Library and open the store page.
  2. Or in VS Code press Ctrl+Shift+X and search SG Neo Theme.
  3. Click Install.
  4. Press Ctrl+K Ctrl+T and pick SG Neo.
Method 2

From .vsix file

  1. Click Install .vsix to download sg-neo-theme.vsix.
  2. In VS Code open Extensions (Ctrl+Shift+X).
  3. Click the … menu (top right of the panel) and choose Install from VSIX…
  4. Select the downloaded file, then pick the theme with Ctrl+K Ctrl+T.

Or use the terminal:

$ code --install-extension sg-neo-theme.vsix
Using VSCodium or Gitpod? Install from Open VSX. Notepad++ users: download the XML and import it via Settings → Style Configurator.
